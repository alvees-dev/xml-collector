Política de Privacidade

Coletor XML

Última atualização: novembro de 2026

1. Quais dados do Google o programa acessa

O programa pede somente a permissão drive.file. Com ela, ele acessa apenas os arquivos e pastas que ele mesmo criou no Google Drive. Ele não vê, não lê e não altera nenhum outro arquivo do Drive, nem e-mails, contatos ou outros dados da conta.

2. Como esses dados são usados

  • O programa cria a pasta "Arquivos XML" e, dentro dela, uma pasta para cada CNPJ.
  • Ele envia para lá o arquivo compactado com os XMLs do mês. Cada envio substitui o arquivo anterior daquele CNPJ.
  • Ele cria um link de acesso à pasta e manda esse link por e-mail ao destinatário que o usuário informou.

3. Onde ficam guardados

  • O login do Google fica guardado somente no computador onde o programa está instalado, na pasta de configuração do programa.
  • Os arquivos ficam no Google Drive da própria conta.
  • Nenhum dado é enviado para servidores do desenvolvedor ou de terceiros.

4. Compartilhamento

Os dados não são vendidos, cedidos nem compartilhados. O único acesso a eles é pelo link da pasta, que vai para o destinatário escolhido pelo usuário.

5. Como remover o acesso

Para remover o acesso do programa a qualquer momento, entre em Conta Google › Segurança › Apps de terceiros com acesso à conta. Para apagar os dados, basta apagar a pasta "Arquivos XML" do Drive.
